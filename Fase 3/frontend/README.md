# Frontend de fase 3

La base existente está en [`fase 2/proyecto_Etapa2_REACT`](../../fase%202/proyecto_Etapa2_REACT/). Esta carpeta reserva el destino de la versión integrada; aún no contiene una copia ni una aplicación ejecutable.

Al comenzar la implementación, copiar aquí el proyecto React sin `node_modules`, `dist` ni `coverage` para conservar intacta la entrega anterior. Adaptar los servicios de datos a llamadas asíncronas con `fetch` o Axios, configurar las dos URLs mediante variables de entorno de Vite y actualizar contextos y páginas para carga, errores y sesión.

No importar usuarios, permisos, crédito ni precios de `localStorage` como datos confiables del backend. El carrito puede continuar local. La implementación deberá restringir el panel del vendedor a consulta, según la propuesta.
